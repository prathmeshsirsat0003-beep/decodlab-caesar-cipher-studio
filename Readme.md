# 🔐 Cyber Vault – Basic Encryption & Decryption

## Project 2 – Cyber Security

A simple web-based encryption and decryption application using the **Caesar Cipher** technique.

## 🎯 Objective

The objective of this project is to understand basic encryption and decryption concepts and implement a simple technique for protecting text data.

## ✨ Features

* 🔒 Encrypt text
* 🔓 Decrypt text
* 🔑 Custom shift key
* 🛡️ Basic data confidentiality
* 🎨 Attractive user interface
* 🧹 Clear input and output
* ⚡ Instant results

## 🛠️ Technologies Used

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The Cyber Vault application will open in your browser.

You can also directly open `index.html` in a web browser.

## 🔐 How It Works

The application uses the Caesar Cipher technique.

For example, with a shift key of `3`:

```text
A → D
B → E
C → F
```

Example:

```text
Input:

HELLO

Shift Key:

3

Encrypted:

KHOOR

Decrypted:

HELLO
```
